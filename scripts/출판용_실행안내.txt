2학년 수학 보드게임 인터넷 실행 방법

1. start-game.cmd를 더블클릭합니다.
   - 만약 검은 창에서 이상한 글자가 나오고 바로 꺼지면 start-game.bat를 실행하세요.
2. 브라우저가 먼저 열리면 선생님 PC 화면이 준비된 것입니다.
3. 처음 실행할 때는 인터넷 접속 도구를 자동으로 내려받습니다.
4. 잠시 기다리면 https://...trycloudflare.com 형식의 인터넷 주소가 표시되고 인터넷 화면이 한 번 더 열립니다.
5. 인터넷 화면에서 QR을 보여 주면 학생 휴대폰은 같은 와이파이가 아니어도 접속할 수 있습니다.
6. 수업 중에는 start-game.cmd로 열린 검은 창 또는 파란 PowerShell 창을 닫지 마세요.
7. 수업이 끝나면 실행 창에서 Enter를 눌러 서버를 종료합니다.

중요
- start-game.cmd로 만든 인터넷 주소는 실행할 때마다 새로 바뀝니다.
- 창을 닫으면 학생 휴대폰 접속도 바로 끊깁니다.
- index.html을 직접 열면 QR 모바일 접속이 되지 않습니다. 반드시 start-game.cmd로 실행해 주세요.
- Windows 보안 또는 방화벽 알림이 나오면 허용을 눌러 주세요.
- 아무 화면도 열리지 않으면 start-game.cmd를 마우스 오른쪽 버튼으로 눌러 '관리자 권한으로 실행'을 시도해 보세요.
- start-game.cmd가 깨져 보이면 같은 폴더의 start-game.bat를 실행하세요.
- 실행 기록은 internet-run.log 파일에 남습니다.

인터넷 주소가 만들어지지 않을 때
- 학교 또는 기관 보안망에서 Cloudflare 임시 접속을 막을 수 있습니다.
- 이때는 start-local.cmd를 사용하세요. 단, start-local.cmd는 선생님 PC와 학생 휴대폰이 같은 와이파이에 있을 때만 됩니다.
- start-local.cmd를 쓰는 경우 방화벽 알림에서 허용을 눌러야 휴대폰 접속이 됩니다.

화면이 자동으로 안 열릴 때
- 실행 창에 표시되는 선생님 화면 주소를 브라우저 주소창에 직접 입력하세요.
- 학생 모바일 주소는 보통 선생님 화면 주소 뒤에 /?m=1 이 붙은 형태입니다.
