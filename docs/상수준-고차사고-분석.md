# 상 수준 조작 문항: 고차적 사고 분석

조작 문항의 **상 수준**을 수만 키운 문항이 아니라 **고차적 사고 과정이 드는 문항**으로 바꾸었습니다. 이 문서는 학년·단원·차시마다 상 문항에 어떤 사고 과정이 들어가는지 정리한 것입니다. 차시별 표(5장)는 앱에 실제로 들어간 문항에서 그대로 뽑았습니다.

## 1. 설계 원칙

- **과제의 인지적 요구 수준(Smith & Stein, 1998)**: 같은 절차를 큰 수로 되풀이하는 과제는 '연결 없는 절차'에 머뭅니다. 상 문항은 '연결 있는 절차'와 '수학하기' 단계를 겨냥해 따지기·거꾸로 생각하기·오류 분석이 들어가게 했습니다.
- **열린 질문과 평행 과제(Marian Small)**: 하·중·상이 같은 개념을 다루면서 상은 답이 여럿인 열린 질문으로 만들었습니다. 바닥은 낮고 천장은 높은 과제입니다.
- **교육과정 내용 체계 안에서**: 문항에 쓰는 수와 용어는 그 차시까지 배운 범위로 제한합니다. 예를 들어 1학년 1학기 1~4단원에는 10 이상의 수를 쓰지 않습니다. 과정·기능 범주의 **추론, 문제해결, 의사소통**과 가치·태도 범주의 **비판적으로 사고하는 태도**를 겨냥합니다.
- **자동 채점과 정답 검사**: 모든 상 문항은 문제 글만 보고 따로 다시 풀어 정답을 확인하는 검사를 거칩니다. 열린 문항은 조건에 맞는 수 전체를 다시 구해 채점 기준과 견줍니다.

## 2. 하·중·상 배치와 풀고 싶게 만드는 장치

- **하·중·상 배치**
  - 그대로 따라 하면 되는 조작은 수가 커도 **하·중**에서 냅니다. 상 갈래의 큰 수·조건 여럿 문항도 중으로 내렸습니다.
  - **상**에는 같은 조작이라도 고차적 사고가 있어야 풀리는 문항(오류 분석, 열린 답)만 냅니다.
- **조작 문항의 양**: 문항 묶음의 둘에 하나쯤을 조작 문항으로 바꿉니다(전에는 셋에 하나). 하 갈래가 없는 차시는 중·상 갈래를 쉬운 수로 냅니다.
- **임무 이름표**: 문제 위에 무엇을 하는 임무인지 보여 줍니다(⏰ 시계 맞추기 임무, 🕵️ 실수 탐정, 🔍 비밀의 수 찾기). 상 문항에는 '도전'을 붙입니다.
- **동물 친구**: 오류 분석 문항에서는 곰돌이·토끼·다람쥐·여우·판다·펭귄이 실수를 해 두고, 아이가 탐정이 되어 고쳐 줍니다.
- **성취감**
  - 맞히면 임무에 맞춘 칭찬과 별(하 1개, 중 2개, 상 3개)이 나옵니다.
  - 열린 답 문항은 조건에 맞는 수를 모두 보여 주어, 숨은 답이 여럿이었다는 것을 알게 합니다.

## 3. 상 수준 고차 문항의 두 갈래

| 갈래 | 학생이 하는 일 | 드는 사고 과정 | 교육과정 연결 |
|---|---|---|---|
| **오류 분석: 친구의 틀린 조작 고치기** | 그 차시의 상 문항을 동물 친구가 먼저 해 두었는데 틀렸습니다. 친구가 무엇을 잘못했는지 찾아 고칩니다. | 조건과 하나씩 맞추어 따지기, 오개념 알아차리기, 바른 방법 설명하기 | 추론, 의사소통, 비판적으로 사고하는 태도 |
| **열린 답: 조건에 맞는 수 찾기** | 조건을 모두 만족하는 수가 여럿입니다. 조건을 따져 그 가운데 하나를 고릅니다. | 두 조건 함께 따지기, 거꾸로 생각하기(결과→처음), 일반화(같은 규칙의 수들) | 추론, 문제해결, 연결 |

친구의 실수는 그 조작에서 아이들이 실제로 자주 하는 실수로 만들었습니다.

| 조작 | 친구의 실수(오개념) |
|---|---|
| 자로 재기·긋기 | 0이 아닌 1 눈금에 맞추기, 시작 눈금을 1로 세기 |
| 시계 | 몇 시 몇 분인데 짧은바늘을 정각 숫자에 두기, 긴바늘과 짧은바늘 바꾸기 |
| 수직선 | 작은 눈금 한 칸을 1로 보기, 큰 눈금 사이를 늘 10칸으로 보기, 소수점 자리 잘못 보기, 반대쪽 큰 눈금에서 거꾸로 세기 |
| 수 모형·돈 | 0인 자리를 건너뛰어 한 자리씩 밀리기(40을 4로), 받아올림(바꾸기)을 하지 않아 10개 넘게 두기, 자리의 모형 수를 서로 바꾸기 |
| 구슬·칸 채우기 | 이미 있는 것을 세지 않고 모두의 수만큼 더 놓기, 이미 있는 수만큼 똑같이 더 놓기, 칠할 부분 대신 남는 부분 칠하기, 100칸에서 줄(0.1)과 칸(0.01) 뒤바꾸기 |
| 차례로 놓기 | 계산 순서에서 곱셈·나눗셈·괄호보다 앞에서부터 계산하기, 자릿수를 보지 않고 맨 앞 숫자만 견주기, 가운데 것끼리 견주지 않기 |
| 각도기 | 반대쪽 눈금 읽기(30°↔150°) |
| 들이·무게 눈금 | 작은 눈금 칸 수를 그대로 mL·g으로 읽기 |
| 막대그래프 | 세로 눈금 한 칸을 1로 보기, 두 항목의 값을 바꾸어 그리기 |
| 달력 | 시작하는 날까지 넣어 세어 하루 어긋나기 |
| 나누어 담기·점 배열 | 몇 개씩 묶기와 똑같이 나누기를 헷갈리기, 남은 것도 한 접시로 세기, 한 줄에 놓는 수와 줄의 수 바꾸기 |
| 도형 이동 | 돌리는 방향·뒤집는 방향을 반대로 생각하기 |
| 꼭짓점·점 찍기 | 대칭축까지의 거리를 두 번 세기, 다른 꼭짓점을 기준으로 옮겨 다른 사각형 만들기, 이등변삼각형 꼭짓점을 밑변 끝 위에 찍기, 중심을 지나지 않는 지름, 원 위의 점을 중심으로 보기 |
| 수직·평행·직각 긋기 | 끝점을 한 칸 비껴 선이 비스듬해지기 |
| 대칭 도형·도형 그리기 | 끝까지 그렸지만 대응점·꼭짓점 하나를 칸 수를 잘못 세어 엉뚱한 곳에 찍기, 비스듬한 변이 있어야 하는데 모두 모눈선에 나란하게 그리기 |
| 대각선 | 대각선 하나의 끝을 꼭짓점이 아닌 점에 잇기 |
| 쌓기나무·부피 | 왼쪽과 오른쪽(앞과 뒤)을 바꾸어 쌓기, 밑면만 한 층 채우고 높이만큼 쌓지 않기 |
| 전개도 | 면 하나를 엉뚱한 자리에 붙이기 |
| 비·비례식 | 몇 배인 관계를 몇 개 더인 관계로 보기(3:4에서 3→9이면 4→10), 비의 앞의 수만큼만 놓기 |
| 비례배분 | 형이 아니라 동생 몫을 표시하기, 비의 합이 아닌 수로 나누기 |
| 백분율·띠그래프·원그래프 | 학생 수를 그대로 칸 수로 칠하기, 20칸 띠에서 한 칸을 10%로 보기, 25명 가운데 1명을 1%로 보기 |

다시 세기만 하면 고칠 수 있는 한 칸 차이 실수(하나 덜·더, 한 칸 어긋남)는 다른 실수를 만들 수 없을 때만 쓰며, 전체 친구 실수의 15%를 넘지 않게 검사합니다(지금 약 9%).

## 4. 학년군·영역별 상 수준의 방향

| 영역 | 1~2학년 | 3~4학년 | 5~6학년 |
|---|---|---|---|
| 수와 연산 | 두 수 사이의 수, 짝수·홀수와 범위를 함께 따지기, □+a의 결과가 조건에 맞는 □ 찾기, 곱셈구구의 곱과 범위 | 어림한 몇백에서 처음 수를 거꾸로 찾기, 나머지가 같은 수의 규칙(검산식), 분수·소수의 크기를 따지는 열린 문항 | 공약수·공배수, 통분하여 사이의 분수 찾기, 백분율의 범위 |
| 변화와 관계 | 규칙을 잘못 이은 무늬 고치기 | 계산식 배열·등호 문항의 오류 분석 | 대응 관계의 식을 거꾸로 따지기, 비례식·비례배분의 오류 분석 |
| 도형과 측정 | 자의 0 눈금, 시계 바늘의 오개념 고치기 | 각도기 반대쪽 눈금, 도형 이동 방향 오류, 수직·평행 긋기 오류 | 이상·이하·초과·미만의 경계, 올림·버림·반올림에서 거꾸로 찾기, 전개도·쌓기나무 오류 |
| 자료와 가능성 | 분류·그래프의 잘못된 곳 찾기 | 그림그래프·막대그래프 오류 고치기 | 목표 평균을 이루는 점수 찾기, 띠·원그래프 오류 고치기 |

## 5. 학년·단원·차시별 상 문항

- 표의 '상 수준 사고 과정'은 그 차시 상 문항에 실제로 나오는 고차 유형입니다.
- **열린 답**은 조건에 맞는 수를 찾는 문항이고, **오류 분석**은 친구가 해 둔 틀린 조작을 고치는 문항입니다.
