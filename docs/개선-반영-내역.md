# 개선 반영 내역

기준: 2026-11-03, 최신 main의 문제집 문항 추가 변경을 보존한 상태에서 개선했습니다.

| 순서 | 분석에서 제안한 항목 | 반영 |
| --- | --- | --- |
| 1 | 전송 실패 시 답안 유실 | IndexedDB 대기열, 수신 확인, 재전송, 동일 ID 중복 제거 |
| 2 | 최근 100개 조회의 누락 | 처음부터 페이지 조회, 저장 성공 후 커서 이동, 지연 도착 답안 재검사 |
| 3 | 백업 검증 | 버전·필수 값·날짜·수치·도움말·중복 ID 검사, 잘못된 묶음 전체 거부 |
| 4 | 힌트 판정 불일치 | 텍스트·풀이 단계·조작 도움 이력을 유지하고 기록·보상에서 동일하게 사용 |
| 5 | 종합 복습 원격 기록 | 차시 메타데이터 전달, 이전 종합 차시 ID 복원, 저장 성공 후 처리 표시 |
| 6 | 원격 오답 자료 부족 | 해설·도움말·그림도 전송·저장 |
| 7 | 배경 이미지 경로 | Vite가 해석하는 자산 경로로 수정 |
| 8 | 검사와 배포 분리 | 배포 빌드가 전체 테스트를 먼저 통과하도록 변경, PR 검사 추가 |
| 9 | 평가 지표 혼합 | 최초 응답·독립 응답·재도전 정답률 구분, 난이도를 고려한 참고 모둠 제안 |
| 10 | 학습 태도 단정 | 짧은 시간 오답을 관찰 근거로 표현, 원인 확인을 위한 지도 제안 |
| 11 | 고차 사고 확인 | 상 문항에 선택형 구두 설명 발문 제공. 설명 능력을 자동 판정하지 않음 |
| 12 | 학급·학년도 혼합 | 학급 설정, QR 정보 전달, 기록장 학급 선택, 이전 기록 별도 유지, 명단·보상 분리 |
| 13 | 저장 실패 알림 | 저장소·자동 백업 실패 및 전송 대기 안내, 재시도 경로 |
| 14 | 로컬 기록·권한 | 수신 확인 전 디스크 저장, 서버 재시작 복구, 조회·초기화의 루프백/별도 교사 키/쿠키 확인 |
| 15 | 무거운 로딩·오류 | 불필요한 부품 선행 로딩 제거, 엔진 오류 안내, 렌더링 복구 경계 |
| 16 | 유지보수 책임 분리 | 범위별 문항 구성·원격 기록 수신·전송 대기열·타이머·엔진 로딩·학급 설정 분리 |
| 17 | 실행·운영 안내 | README, 저장 위치·백업 범위·기기 변경·보안 안내, 사용자 경로에 의존하지 않는 실행 파일 |

추가로 타이머는 interval 횟수 대신 실제 경과 시간을 사용하고, CSV의 수식 시작 문자도 보호합니다. 긴 한글 HTTP 요청을 끝까지 읽도록 PowerShell 서버를 보완했습니다.

## 검증

- 기존 전 학년 문항 검산·시각화·차시 범위·게임 규칙 테스트를 유지합니다.
- 가상 IndexedDB에서 저장·삭제·되돌리기·불완전 백업 거부를 검사합니다.
- 전송 실패와 모듈 재시작 후 대기열 복구, 250개 답안 페이지 조회, 수신 확인 후 삭제를 검사합니다.
- 저장 실패 시 원격 수신 커서를 앞당기지 않는지 검사합니다.
- Node 및 Windows PowerShell 서버를 실제로 시작해 중복 요청, 긴 한글, 교사 권한, 재시작 후 복원을 검사합니다.
- DOM 통합 검사에서 일반 힌트를 열었다 접은 뒤 답해도 힌트 이력·QR 학급 정보가 전송되는지 검사합니다.
- 타이머 지연·보너스·재시작과 학급별 식별·기존 보상의 일회성 이동을 검사합니다.

## 이 변경으로 완료하지 않은 운영·검증 범위

**실제 Firebase 보안 규칙·교사/학생 로그인·방 만료 정책은 미적용**입니다. 계정 관리 권한과 인증 서버 구성이 필요하며, 현재 REST 클라이언트에 규칙만 먼저 적용하면 연동이 끊깁니다. 운영 적용 순서는 [운영·보안 안내](운영-보안-안내.md)에 적었습니다. 실제 학생 기록을 읽거나 삭제하지 않았습니다.

**학년별 생성기 분리**는 후속 변경에서 반영했습니다. [추가 개선·검증](추가-개선-검증.md)을 참조하세요. 이번에는 공통 출제 흐름과 화면의 책임을 나누고 부품의 불필요한 선행 로드를 제거했습니다. 수만 줄의 생성기를 대규모로 재작성하지 않고 독립 검산 체계를 보존했습니다. 대형 엔진 청크 경고는 남을 수 있습니다.

**전자칠판·휴대폰의 실제 동시 터치와 PDF 인쇄 품질**은 실기기 검증이 필요합니다. 최초 변경에서는 브라우저 제어가 중단됐으나 후속 변경에서 실제 브라우저 수업·오답 저장·PDF 생성과 두 쪽 렌더링을 확인했습니다. 실물 장치 검증은 남아 있습니다. 자동 검사 통과를 실기기 화면 검증 완료로 표현하지 않습니다.

추가 보안 검토에 따라 교사 세션 발급에 별도 비밀키를 요구하고 DNS 주소 목록을 제거했습니다. 인터넷 실행기도 중복 내장 서버 대신 같은 검증된 서버를 사용합니다. 로그·실행 스크립트·임의 JSON 파일을 정적 웹 경로로 내려받지 못하게 제한했습니다.
