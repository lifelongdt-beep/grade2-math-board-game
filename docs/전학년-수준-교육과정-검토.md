# 전 학년 수준·교육과정 검토

## 범위와 재현

1~6학년 양 학기의 교과 자료 499개 차시, 71개 단원을 대상으로 하·중·상과 첫째·둘째 판을 생성한다. 일반 생성 경로와 실제 수업의 도입 복습·조작 혼합 경로를 각각 확인하고, 추가된 70개 단원 놀이도 세 수준으로 생성한다.

```sh
pnpm audit:curriculum
pnpm audit:curriculum --runtime
node scripts/audit/compare.mjs
pnpm test
pnpm build
```

원시 결과는 `output/audit/static`, `output/audit/runtime`에 저장한다. 각 차시·수준·판·경로의 문항 수와 사고 단계 분포, 전체 문항 내용의 SHA-256을 기록한다. `compare.mjs`는 두 엔진의 모든 은행을 비교하고 하나라도 다르면 실패한다. `전학년-검토-coverage.json`은 이 검토의 학기별 요약이다.

2026-11-06 결과: 경로별로 6,198개 문항 묶음, 196,178개 생성 문항 표본(일반 경로 91,697개)을 확인했다. 검사 규칙의 잔여 발견 사항은 0건이고 두 엔진의 내용 차이도 0건이다. 이 수는 고유 문항 수가 아니라 수준·판·경로별 생성 결과의 합계다.

## 확인하여 수정한 문제

- 공통 생성기의 마지막 채우기 과정에서 수준 제한을 무시하여, 상에 단순 지식형이나 하에 사고형이 들어올 수 있었다. 수준 제한을 마지막까지 유지한다. 도입 복습은 선수 개념을 확인하므로 이 제한에서 제외한다. 수준에 맞는 새 문항이 부족하면 문항 수를 줄이고 다른 수준으로 채우지 않는다.
- “바르게 읽은”이라는 표현만으로 단순 수 읽기를 고차 사고로 분류하던 규칙을 고쳤다.
- 1학년 시계 문항의 오답 선택지에 임의의 분 단위가 나오고, 정각 차시에서 30분을 미리 묻던 유형을 수정했다. 공통 시간 풀이가 1학년에 5분씩 세기·곱셈을 덧붙이지 않도록 해당 학년의 자체 풀이를 유지한다.
- 2학년 시계의 나눗셈식 설명을 5분씩 뛰어 세기로 바꾸었다. 두 자리 수 곱셈 등을 전제하던 도움말은 묶음 수와 반복 덧셈으로 설명한다. 정답·선택지의 수를 바꾸는 처리가 아니다.
- 차시와 무관한 공통 핵심 개념 대신 문항에 명시한 개념을 우선한다. 개별 개념이 없으면 교과 차시의 초점을 쓰며, 도입은 선수 개념 설명을 유지한다.
- 수준 제한 후 부족해지는 3학년 분수·나눗셈·들이, 5학년 분수와 소수 비교·합동·가능성 차시에 적합한 유형을 추가했다. 새 유형은 각각 80개 시드에서 문제 조건을 다시 해석하여 답을 검산한다.
- 테스트용 전체 엔진에만 등록되어 있던 3학년 양 학기와 4학년 1학기 보충 은행을 실제 앱의 지연 로딩 엔진에도 등록했다.
- 보충 유형과 기존 격자 경로 설명의 수 뒤 조사를 수정했다.

## 해석과 한계

선택지 수는 조작 문항을 제외하고 2~4개를 허용하며 중복·정답 인덱스·정답의 유일성을 확인한다. 단원 놀이는 짧은 핵심 회상 문제와 속도 차이를 사용하는 별도 모드이므로 일반 교과 문항의 사고 단계 제한을 적용하지 않는다.

이 검토는 모든 등록 차시를 포함하는 생성 표본 검사이며, 가능한 모든 난수 시드의 문항을 사람이 전수 검수했다는 뜻은 아니다. 공통 검사에서는 선택지·잘못된 값·학년별 선수 범위·수준 혼입을 확인하고, 기존 단원별 검산 테스트와 새 유형의 독립 검산을 함께 실행한다. 모든 표본의 수학적 정답을 범용 계산기로 다시 풀었다거나 모든 화면을 시각적으로 확인했다는 주장과 구분한다.
