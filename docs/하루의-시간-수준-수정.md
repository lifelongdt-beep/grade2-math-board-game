# 2학년 2학기 하루의 시간 차시 수준 수정

대상: 4단원 7차시 ‘하루의 시간을 알아볼까요’.

확인한 문제는 하에 여러 날을 시간으로 바꾸는 큰 수 계산이 들어가고, 중에 하와 같은 12+12 문항이 반복되며, 상에 시차·빨라지는 시계·밤을 넘긴 분 계산이 섞이는 것이었습니다. 차시 목표 ‘하루 24시간과 오전·오후’ 안에서 사고 단계를 구분하도록 바꿨습니다.

| 수준 | 출제 기준 | 예시 |
|---|---|---|
| 하 | 하루·오전·오후의 뜻과 생활 시각 직접 구별 | 아침 8시를 오전·오후를 넣어 나타내기 |
| 중 | 생활표에서 정보를 읽거나 하루 개념 한 번 적용 | 오전과 오후 시각의 앞뒤 비교, 낮 12시를 기준으로 외출 시간 구하기 |
| 상 | 같은 하루 개념으로 두 조건 연결·역추론·오류 설명 | 시작·끝 시각이 모두 다른 두 일정 비교, 날짜와 오전·오후를 함께 고치기 |

차시 전용 `s22day.ts`를 사용하므로 기존 기본 문항·확장 문항이 수준에 다시 섞이지 않습니다. 첫 판은 수준마다 6가지 유형, 30문항입니다. 이후 판은 앞 판과 같은 문제를 제외하므로 개념형 문항의 새 변형이 소진되면 문항 수가 줄 수 있습니다.

시차·시계 오차·여러 날의 시간 환산·분 계산 유형은 이 차시에서 폐기했습니다. 20개 판의 문제 글을 별도 검산기로 읽어 답·보기·중복 여부를 검사합니다. 하의 계산 부담, 중·상의 같은 문제 중복, 차시 밖 계산이 재등장하는지도 검사합니다. 풀이 과정 문항은 중 5개, 상 15개이며, 단계 수만으로 수준을 높이지 않고 실제로 요구하는 사고를 다르게 했습니다.
